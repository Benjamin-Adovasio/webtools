Port Check

Test TCP connectivity from the Adovasio server to a public host and port.

Enter a public host and port, then select Check port.
About this check

Test a public TCP service.

A port is a numbered connection point used by services such as HTTPS, mail, and remote access.

This check attempts a TCP connection from the Adovasio server. Firewalls and access rules can affect the result.
