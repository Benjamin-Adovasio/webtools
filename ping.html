Ping Test

Send three ICMP packets from the Adovasio server to a public host.

Enter a public host and select Ping host.
About this check

A quick reachability signal.

Ping measures whether a public host responds to a small ICMP request sent from the Adovasio server.

Some healthy hosts block ICMP traffic, so a missing reply does not always mean the service itself is offline.
